数据与隐私

角色、会话、摘要、长期记忆、日志全部保存在本机数据目录（界面设置里可查看路径）。默认 mock 模式不联网；配置本地模型（Ollama / LM Studio）只访问本机；配置云端 API 后，对话内容会发送到你填写的那家服务。语音识别与语音合成同样全部本地运行。

语音对话

点输入框旁的 🎤 开始说话，再点一次结束：语音会被本地识别成文字并发送。角色的每条回复带 🔊 按钮，点击用所选音色（女声·晓晓 / 男声·云间）本地合成语音朗读；可在 ⚙ 设置 中开启自动朗读。

「模型生成的回复」vs「存储的记忆」

聊天区里带 模型生成 标记的气泡是模型当轮输出，仅作为消息保存；带 已存储记忆 的卡片是长期记忆库的条目，会在之后每轮按相关性被引用。两者完全分开。

记忆规则

·「记住：…」开头 → 立即写入长期记忆（用户记忆）
·「记住关于角色：…」→ 写入当前角色的角色记忆
·「忘记：…」→ 删除匹配记忆；「忘记：全部」→ 清空
· 普通消息由启发式规则/模型定期提取，宁缺毋滥；角色扮演里的虚构剧情不会变成关于你的事实
· 检索用可解释的关键词打分（BM25 类），引用分数与命中词均可见
